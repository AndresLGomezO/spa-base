# Component: sidebar-nav

Sidebar navigation items container with shared templates for group, subgroup, and raw items.

**Properties:** groupItem: { rows, styles?, motion? }, subgroupItem: { rows, styles?, motion? }, rawItem: { rows, styles?, motion? }, styles?

```json
{
  "kind": "sidebar-nav",
  "groupItem": {
    "rows": []
  },
  "subgroupItem": {
    "rows": []
  },
  "rawItem": {
    "rows": []
  }
}
```
