# Component: sidebar-collapse

Sidebar collapse/expand control with configurable icons and styles.

**Properties:** iconName?: string (default PanelLeftClose), expandIconName?: string (default PanelLeft), iconSize?, styles?

```json
{
  "kind": "sidebar-collapse",
  "iconName": "PanelLeftClose",
  "expandIconName": "PanelLeft"
}
```
