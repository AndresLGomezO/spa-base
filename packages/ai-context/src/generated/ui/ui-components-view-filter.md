# Component: view-filter

Page-global filter control; pick entity/field pairs from the full data model on demand. Bound to URL `f.{entity}.{field}`.

**Properties:** filters, styles?

```json
{
  "kind": "view-filter",
  "filters": [
    {
      "entityName": "account",
      "fieldName": "accountType"
    }
  ]
}
```
